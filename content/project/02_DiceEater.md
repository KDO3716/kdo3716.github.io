## 게임 소개
- 출   시 : 2025년 3월 11일 (Steam 얼리 액세스)
- 개   발 : ㈜ 팀 테트라포드
- 장   르 : 추리, 카드게임 (스테퍼 케이스 스핀오프)
- 플랫폼 : Steam, Stove
## 프로젝트 개요
* 기   간 : 2025.02
* 소   속 : ㈜ 팀 테트라포드
* 직   책 : 프리랜서 사원
* 직   무 : QA
* 업   무 : QA 프로세스 구축, 버그 리포트 작성, 스크립트 작업 외
* 성   과 : CBT 빌드 안정화, 스크립트 검수, 사용자 경험 개선
* 스   킬 : QA, 스크립트 검수, 애니메이션 연출, UX 개선 제안
* 도   구 : Google Sheets, Xbox Game Bar
## 업무 요약
- 기본 앱을 활용한 버그 추적 시스템, 테스트 프로세스 구축
- 알파 테스트 버전 탐색적 테스트 및 버그 리포트 작성, CBT 빌드 안정화
- 캐릭터 스크립트 검수·교정 및 감정 표현 애니메이션 매칭, 적용
- 가이드 화면, 주사위 선택 화면 등 UI 수정 제안서 작성

## QA 프로세스 구축 및 버그 리포트 작성
* Google Sheets, Xbox Game Bar 등 기본 앱을 사용해 버그 추적 시스템과 테스트 프로세스 구축
* 알파 테스트 버전의 탐색적 테스트 수행, 버그 리포트 작성
* 게임 플레이에 치명적인 버그를 탐색해 CBT 빌드 배포 전까지 안정화에 기여

## 캐릭터 스크립트 검수 및 애니메이션 적용
* 스크립트 내 고유명사, 맞춤법, 서식 및 텍스트 오류를 찾아 교정·수정 진행
* 대사와 어울리는 감정 표현 애니메이션을 매칭하고 시트 작성, 스크립트 적용
* 빌드 품질 기준에 맞춰 텍스트 오류 최소화, 애니메이션 연출 향상에 기여

## 사용자 경험 개선 및 UI 수정 제안
* 게임 진행에 방해되는 비직관적인 정보 전달 요소를 찾고, 개선 방안을 포함한 수정 제안서 작성
* '가이드 화면'과 '주사위 선택 화면'의 표시 방식을 유저 친화적으로 수정할 수 있도록 제안
* NPC의 스킬 트리거 타이밍을 조절해 플레이어의 전략적 대응을 유도하고 인터페이스 가독성 확보

## 회고
- 한 달이라는 짧은 기간 동안 CBT 빌드 배포 일정에 맞춰 작업해야 했습니다. Google Sheets와 Xbox Game Bar 같은 기본 앱으로 빠르게 버그 추적 환경을 갖추고, 게임 플레이에 치명적인 버그를 우선 탐색해 빌드 안정화에 집중했습니다.
- QA 외에도 캐릭터 스크립트 검수와 감정 표현 애니메이션 적용을 함께 맡으며, 텍스트와 연출이 캐릭터의 인상과 몰입감에 미치는 영향을 체감할 수 있었습니다.
- 규칙이 독특한 보드게임 장르인 만큼, 정보 전달 방식과 NPC 스킬 타이밍이 플레이어의 이해와 전략적 판단에 큰 영향을 준다는 것을 확인했고, 이를 바탕으로 UI 수정 제안서를 작성했습니다.
