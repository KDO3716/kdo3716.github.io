## 게임 소개
- 출   시 : 2023년 4월 30일 (얼리 액세스 2023년 3월 10일), Nintendo Switch 2025년 5월 29일
- 개   발 : 팀 테트라포드
- 장   르 : 추리, 어드벤처
- 플랫폼 : Steam, Stove, Nintendo Switch
## 프로젝트 개요
* 기   간 : 2022.12 - 2023.03
* 소   속 : 팀 테트라포드
* 직   책 : 인디 프로젝트 외부 지원
* 직   무 : QA
* 업   무 : QA 워크플로우 구축, 버그 리포트 작성
* 성   과 : 개발팀 업무 지원, 버그 탐색 및 품질 향상에 기여
* 스   킬 : QA, 테스트 설계, UX 개선 제안
* 도   구 : 캡처 도구, 메모장
## 업무 요약
- 기본 앱을 활용한 간이 테스트 워크플로우 구축 및 버그 리포트 작성
- 버그 등급 3단계 축소, 버그 유형별 담당자 배치로 처리 효율화
- 결함 집중(Defect Clustering)을 고려한 테스트 설계 및 탐색적 테스트 수행
- 시나리오 분기, 텍스트 가독성, UI 하이라이트 등 사용자 경험 개선 제안

## 간이 QA 프로세스 구축, 버그 리포트 작성
* 캡처 도구, 메모장 등 기본 앱을 사용해 테스트 워크플로우 구축 및 버그 리포트 작성
* 빠른 작업을 위해 개발팀과 협의 후 버그 등급을 3단계로 축소하고 버그 유형에 따라 담당자 배치 진행
* 개발팀 업무 효율에 크게 기여해 조직 내 우수한 평가를 받음

## 결함 집중(Defect Clustering)을 고려한 테스트 설계
* 상용 라이브러리로만 구현된 부분과 팀 내에서 직접 개발된 부분을 분리해 결함 집중을 예측
* 해당 기능을 사용한 '단서 조합', '추리' 장면을 중심으로 탐색적 테스트 수행
* 약 40% 분량의 버그가 해당 부분에서 발견되었으며, 상당수 치명적인 버그 탐색에 기여

## 사용자 경험 개선 및 UI 수정 제안
* 시나리오 분기점 적용 방식이 흐름을 방해하지 않도록 변경 제안, 어려운 문장을 다듬어 사용자 경험 개선
* 가독성을 고려해 텍스트 색상과 스타일 변경, UI 하이라이트 적용을 제안
* 기간 내 수행 가능한 제안사항을 부분 적용하고 게임 품질 향상에 소폭 기여

## 회고
- 별도의 버그 트래킹 도구가 없는 소규모 인디 개발 환경에서, 캡처 도구와 메모장 같은 기본 앱만으로도 테스트 워크플로우를 구축할 수 있었습니다. 개발팀과 협의해 버그 등급을 단순화하고 담당자를 나누면서, 도구보다 팀 상황에 맞는 프로세스가 더 중요하다는 것을 배웠습니다.
- 결함 집중 원리를 적용해 직접 개발된 기능에 테스트를 집중한 결과, 전체 버그의 약 40%를 해당 부분에서 찾을 수 있었습니다. 테스트 설계 단계에서의 예측이 한정된 시간 안에 효과적인 결과를 만든다는 것을 경험했습니다.
- 사용자 경험 개선 제안은 일정상 일부만 반영되었지만, 플레이어 관점에서 흐름과 가독성을 점검하는 시각을 기를 수 있었습니다.
